# 자바스크립트에서 객체가 저장되는 방법

## 정의


- 자바스크립트에서 객체는 heap에 저장됩니다.

키워드

- <b>바인딩</b>
- <b>참조</b>
- 스택
- 힙
- 주솟값

## 특징


- 스택에서는 객체의 주솟값을 바인딩하고, 힙에서는 객체를 저장하고 있다.
  - <b>객체는 힙에 생성되고 변수는 객체에 대한 참조를 가리킨다. </b>

<image source="notion-file-block://893ee90a-967f-831d-bd88-01fe118752d9/163d84c5-3883-49df-be59-f055519dbc0d?space_id=0c13a87e-ef61-4fd0-af8a-e953a2e82e45&name=image.png" />

- <b>객체 생성:</b> 일반적으로 힙에 객체를 할당한다.
- <b>변수: </b>객체 자체가 아니라 객체를 가리키는 참조를 가진다.
- <b>함수 호출: </b>실행 컨텍스트가 만들어져 콜 스택에서 실행된다.
- <b>Closure: </b>함수 실행이 끝나도 필요한 렉시컬 환경은 참조가 유지되는 동안 살아 있을 수 있다.
